# Crazy UI

- **Aurora background:** a slow, drifting colour glow behind the whole app.
- **Accent picker:** five colour themes (Forest, Sunset, Ocean, Grape, Candy) in the sidebar. The
  choice changes the buttons, bubbles and highlights, and is remembered in this browser.
- **Confetti:** a message containing 🎉, 🥳, 🎊 or 🎂 bursts confetti once when it arrives.
- **Motion:** message bubbles spring in and lift on hover; sidebar rooms nudge on hover.
- **Reduced motion:** when the system asks for less motion, the background, bubble animation and
  confetti are switched off.

Implemented in `frontend/src/features/crazyUi.js` and `crazyUi.css`, with no shared files changed.
